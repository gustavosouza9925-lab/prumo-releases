# Prumo — distribuição

Canal público de distribuição do aplicativo **Prumo** (finanças pessoais para Android).

Este repositório contém **apenas** os APKs assinados e o arquivo `update.json` usado pelo atualizador do app.
O código-fonte é privado.

## Instalar

1. Abra a [última versão](../../releases/latest) no celular e baixe `prumo-<versão>.apk`.
2. Permita a instalação de apps desta fonte quando o Android pedir.
3. Confirme a instalação.

Atualizações seguintes podem ser feitas pelo próprio app (Mais › Atualizações). O app confere o SHA-256 e a
assinatura antes de abrir o instalador; seus dados locais são preservados.

## Verificar o arquivo
